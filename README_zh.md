# ForeverWatch

[English](README.md) | **简体中文**

专为 **魔兽世界 Forever (`1.60.1` / Interface `16001`)** 打造的 **周围敌情自动监控 + 玩家标签** 插件。

自动监测附近敌对玩家的攻击与击杀行为并动态提升危险等级、自动记录【仇人】，通过多人堆叠屏幕预警横幅与可锁定半透明悬浮雷达实时提醒；同时支持在游戏内全场景右键给己方与敌对玩家打标签，并在 Tooltip、聊天栏与姓名板清晰展示。

---

## 核心功能

### 1. 自动敌情监控与仇人预警
- **动态危险等级体系**：
  - **Lv.1 危险人物**：攻击我方玩家
  - **Lv.2 极度危险**：击杀我方 1–2 人
  - **Lv.3 嗜血杀手**：击杀我方 3–4 人
  - **Lv.4 战场屠夫**：击杀我方 5–9 人
  - **Lv.5 灭世魔头**：击杀我方 10 人及以上
  - **仇人（最高优先级）**：击杀“我”后自动结合 `C_DeathRecap` 与战斗追踪锁定凶手，记为【仇人】并可继续叠加击杀等级
- **多人并发堆叠预警横幅**：
  - 屏幕上方最多同时堆叠显示 3 条预警横幅（仇人始终置顶，同人自动去重刷新）
  - 4 人及以上并发触发时自动弹出底部汇总警示条，配合 1.5 秒音效节流不炸耳
- **可锁定悬浮敌情监控面板**：
  - 固定最大高度（优先展示威胁最高的前 8 名敌对玩家 + 底部溢出人数提示），内置百人混战刷新节流防卡顿
  - **锁定防误触模式**：点击标题栏锁头（或 `/fw lock`）后自动隐藏设置/折叠图标、列表区域完全鼠标穿透，并变为半透明（设置中 `20%–100%` 实时可调）

### 2. 全场景玩家打标签系统
- **右键菜单全覆盖**：
  - 支持右键目标/焦点头像、小队/团队框架、公会/社区名单、聊天栏玩家名、好友列表、战网好友、**最近盟友（Recent Allies）** 以及 **敌对玩家**（敌对玩家支持一键打标签 + 一键记仇人）
- **多位置清晰展示**：
  - **Tooltip 鼠标提示**：名字旁自动加标记图标，下方展示彩色标签、详细备注与敌对危险记录（支持世界单位、好友列表与最近盟友）
  - **聊天栏**：通过 Forever 原生 `ChatFrameUtil.AddSenderNameFilter` 在发言玩家名字旁直接显示彩色标签
  - **姓名板**：名字旁显示紧凑标记符号（兼容暴雪原生姓名板与 `BetterBlizzPlates`）
- **高度自定义与完整多语言**：
  - 内置 4 种高清游戏内标记图标（图钉标 / 便签标 / 铅笔标 / 高清星）、7 种标签颜色、可自定义快捷预设标签
  - 内置 **简体中文 / 繁體中文 / English** 三语，支持自动跟随客户端或在设置中一键切换

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `/fw` | 打开敌情监控与玩家标签管理窗口 |
| `/fw radar` | 显示或隐藏附近敌情监控悬浮小面板 |
| `/fw lock` | 锁定或解锁悬浮小面板（锁定后防拖拽且鼠标穿透） |
| `/fw tag [玩家名]` | 给当前目标或指定玩家打标签 |
| `/fw nemesis [玩家名]` | 手动将目标或指定敌对玩家记为仇人 |
| `/fw lang [auto\|zhCN\|zhTW\|enUS]` | 切换插件界面语言 |
| `/fw test [multi]` | 预览单人或多人并发预警横幅 |

## 安装方法

1. 前往 [GitHub Releases](https://github.com/AlphaBoom/ForeverWatch/releases) 下载最新版本的 `ForeverWatch-v*.zip`。
2. 将压缩包内的 `ForeverWatch` 文件夹解压至：
   ```text
   World of Warcraft\_forever_\Interface\AddOns\ForeverWatch
   ```
3. 启动《魔兽世界：Forever》，在插件列表中勾选 **ForeverWatch** 即可使用。
